# Yanran Chen — personal website

A concise, dependency-free academic website for GitHub Pages, with a separate publication-page
template and a responsive light/dark design.

## Preview locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Customize

- Edit biography, news, publications, and project links in `index.html`.
- Adjust colors, spacing, and typography in `styles.css`.
- Replace the GitHub avatar URL in `index.html` with a local image if desired.
- Add a CV PDF and link it from the navigation when ready.

## Publish

Commit and push the files to the repository's default branch. In GitHub repository settings, enable
GitHub Pages with **Deploy from a branch** and select the repository root.
